# NexBrowser Automation

This distributable skill guides web automation through the unified NexBrowser MCP server.

It covers managed-window discovery and connection, navigation, form interaction, data extraction, screenshots, file uploads, tabs, dynamic content, and failure diagnosis. All required environment-management and automation tools are provided by the same unified NexBrowser MCP server.
