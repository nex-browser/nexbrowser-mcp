# Support

Use GitHub Discussions or issues for installation questions, reproducible bugs, and feature requests after searching for an existing report.

Include the following when it is safe to share:

- NexBrowser MCP version
- Node.js version and operating system
- MCP client name and version
- NexBrowser Desktop version
- The tool name and a minimal redacted error message
- Reproduction steps that do not contain private browser data

Do not post API keys, CDP endpoints, cookies, authorization headers, screenshots of private pages, or unredacted network logs. Report suspected vulnerabilities privately using the process in `SECURITY.md`, not through a public issue.
